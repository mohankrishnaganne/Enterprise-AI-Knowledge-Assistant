# =============================================================================
# Runtime dependencies — enough to serve requests with HOSTED embeddings.
#
# Deliberately contains no torch and no `--extra-index-url`. Two hard-won reasons:
#
#   1. Streamlit Community Cloud runs Python 3.14, where torch 2.5.x has no wheels
#      at all, and the PyPI Linux build of any version pulls ~2.5GB of CUDA
#      packages that a free tier cannot hold.
#   2. `--extra-index-url` breaks uv (which Streamlit Cloud uses). uv only
#      considers the first index that publishes a package name, to prevent
#      dependency-confusion attacks, so pinned versions of anything the PyTorch
#      index happens to mirror — `requests`, for one — become unresolvable.
#
# With EMBEDDING_BACKEND=hf_api, embeddings come from the HuggingFace Inference
# API. It serves the same BAAI/bge-small-en-v1.5 and returns identical vectors
# (measured at cosine 1.000000), so the same Pinecone index and the same benchmark
# results apply either way.
#
# For local embeddings instead, install requirements-embeddings.txt.
# =============================================================================
